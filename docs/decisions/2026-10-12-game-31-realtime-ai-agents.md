# ADR · 2026-10-12 · 31名可连续决策NPC与可选本机LLM

## 需求 / 证据 / 约束

用户希望游戏中所有NPC像AI一样思考，能在实时环境中自行决定做什么。核验现有代码：v2浏览器引擎按玩家操作推进时钟，31名S级人物每小时记录预设时段活动，社交和消息有有限约束；但缺少实时自主时钟、NPC独立目标与连续记忆、真正大语言模型调用。世界书权威仍为v33，正式世界2026-10-09无创建玩家、钟点未知、正式历史为空，不能为了展示NPC行为擅自解冻。仓库现有CHANGELOG要求最新在最上。

## 方案比较与决定

- 不选择单纯增加随机NPC对白并宣称“AI思考”：这无法解决行为一致性。
- 不选择前端直存云端API密钥：静态页面密钥易泄露，而且浏览器关闭后不持续运行；会产生未授权费用。
- 采用可运行的**混合代理架构**：浏览器JS维持每个NPC独立目标、需求、记忆、下一次计划时间、允许候选及行动审计；玩家明确点击开启时，浏览器每秒推进1/5/10模拟分钟；所有31人约每30模拟分钟运行有约束决策。额外可本机启动Ollama与127.0.0.1 Python标准库代理，单线程顺序请求真实语言模型作为选择器；模型只能在当前候选集合内提出行动，浏览器再次验证，拒绝过期、违反既有工作/家庭/学校时段以及无法理解的输出。模型失败时规则模式照常运行，但日志不伪称为LLM完成。
- 无真实银行/地理/政务权限或可信个人资料的数据一律维持U；全部人格设定、需求指标和模型生成动作在本次分支仍为S级模拟。NPC对其他人的信息有私有边界，只有合法事件传播知识。

## 具体运行语义

1. 浏览器实时钟**默认暂停**。玩家启动后才自动推进本次独立S级游戏时钟；浏览器关闭不会后台积累世界事件，也不会在下一次打开追算关闭期间的墙钟时间。模型运行期间强制1游戏分钟/秒以减少模型输出过期。
2. 游戏中所有NPC始终按本地有限规划器完成到期决策；可选LLM是一个额外的**真实模型仲裁/修订层**，而非31个并发独立模型。模型请求速率受到本机推理延迟和网络超时限制；不能声称“每秒31次模型推理”。
3. 认知快照只包含选定NPC既有已知消息、私有记忆、职业轮廓、当前目标、需求和候选行动；代理对输出采用JSON结构及候选白名单检查，浏览器继续检查当前游戏时刻与现行义务状态。不存在聊天工具调用或自由写数据库操作。
4. NPC行为的相对合理性由可公开审计的规则与模型选择共同保证，但远未覆盖完整经济、法律、物理路径、长期心理模型，也不是真实自然人的历史还原。
