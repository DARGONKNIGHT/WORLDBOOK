# 决策记录 · 2026-10-10 · 游戏人物自主行为2.0与更新日志

## 问题、证据与限制
用户指出旧游戏人物响应失真、NPC没有可选的自主活动，要求仓库新增最新版在上的更新日志。核对仓库已提交的 game/engine.js、game/app.js、game/index.html、世界书NPC索引、v15独立Python决策器与主档案；旧版的social随机抽取31人并立即授予联系方式，reply输出固定句式，自主活动随机在一天中生成单条空泛短句，确实不能兑现有限理性人物行为的目标。

基准世界书版本v33.0，旧游戏v1.0.0；现实R、游戏设定S、未知U。所有31名人物仍为虚构档案，居住区、游戏中的营业/工作日程均是**新明确的S级假设**，没有来源支持将其称作现真人物信息。正式世界无玩家、无事件历史、基准2026-10-09冻结的边界不变。

## 方案取舍

选择保留原生离线JS，在同一个事件队列与统一时间钟内引入明确的决策规则、有限工作/家务/休息模板、优先级、可拒绝、同区接触门槛、NPC已有亲属/同事之间延迟信息流和玩家的审计控制台。没有接入能自由对话的外部语言模型：其联网费用、数据合规与幻觉风险尚未解决，不能凭API生成就称人物具备真实人格。没有宣称与Python v15 planner的代码/状态机实现同构，仅遵循其**承诺优先、检查日程、信息有来源、合理不作为**的可审计原则。

消息从“送出即等待随机答复”调整为网络送达、适当时段阅读、自主决定是否回复；借贷/就业等敏感承诺必须谨慎拒绝或要求走真实流程，不臆造债务、工作关系或交易成功。社交需要同区与公共活动时段、本人自愿；即使发生交谈也不自动成为联系人，拒绝不可重复骚扰。背景家人/同事沟通仅依据世界书原有关系网络，不外推真实隐情。

## 交互与数据边界

社会后台提供启停、审计粒度、单人决策审查、1h/4h模拟推进；不是“直接命令NPC去做事”，玩家不能越权修改NPC意愿。关闭浏览器后不持续运行。社会后台只能由玩家从元视角访问，不传入角色已知信息。v1存档采用保守的schema1→2一次性迁移，原历史条目保持原样、不倒改当时选择，已建立旧版联系人保持，以免悄悄丢存档。

原仓库没有CHANGELOG.md，因此补上根目录倒序更新历史（Game 2.0.0置顶），在 README 和 AGENTS.md 追加入口和未来维护规则，脚本检查日期和游戏版本倒序，CI实施防回归。

变更文件：game/engine.js、game/index.html、game/app.js、game/style.css、game/tests/engine.test.cjs、game/earth-realism.html、game/README.md；新建 CHANGELOG.md、scripts/check_changelog.py；修改 README.md、AGENTS.md、docs/SYNC_STATUS.md 与 .github/workflows/game-tests.yml。测试增加NPC日程与休息、消息时间边界、拒绝与同意、两人关系协商、旧存档迁移、长时间独立后台推进以及单文件生成一致性。具体CI结果按GitHub Actions最终运行记录记载。
