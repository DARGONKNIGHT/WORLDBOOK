# ADR-0001：以GitHub实际数据为世界书唯一可检验主档案

**状态：采用** ｜ **日期：2026-10-10** ｜ **仓库：DARGONKNIGHT/WORLDBOOK** ｜ **游戏基准：2026-10-09**

## 用户要求
仓库必须有完整的世界书内容与项目所引用的真实数据，而不是摘要和链接；今后每次推进先读取GitHub，再提交分析结论、数据、决定和修改记录。

## 初始核查
- 仓库已有v13/v14源码、测试及生成ZIP、31名虚构NPC、43项外部资源入口索引。
- v2—v12单章节仅约数百字，不能证明是早期聊天的原始全量正文。
- 现有资源目录大多标`INDEX_ONLY`，路网原始PBF和宏观经济原始API应答此前不在仓库。

## 决定
1. 将`AGENTS.md`设为新会话进场检查清单。
2. `data/raw/`保存实际合法可再分发字节，`data/manifest.json`记录来源、日期、SHA256、大小和许可；区分来源目录与已入库数据。
3. 为2026-10-09冻结时点优先采集**2026-10-01北京OSM月度历史快照**，而非不确定时间的`latest`。
4. 为经济统计建立国家级机器可读原始快照，并标明年度数据与发布日期的区别；不能自动将后来公布的统计当作冻结日期当时已知。
5. 所有版本迭代都增加ADR决策记录、差异与测试结果。不要在公开仓库保存任何内部隐藏推理链。

## 依据与取舍
- 北京Geofabrik OSM历史档案提供约37MB PBF，可作为**地图覆盖**而非实时交通，© OpenStreetMap contributors，ODbL 1.0。
- 全国OSM快照约1.5GB，不适宜以普通Git提交；需LFS、Release或对象存储并提供SHA256。
- World Bank公开Indicator API可提取时间段内的指标，需核查许可证及数据首次公布日期。
- 对不支持再分发的地图/实时平台数据只登记来源、接口条件、无法上传的原因，不绕过许可。
- 隐藏思维链不是可供版本管理的普通工作产物；可复核的证据、理由、结论、计算、失败记录均应存档。

## 未解决事项
- v2—v12的逐字聊天导出尚未取得，不能宣称全量原文完成。
- 路网和经济文件以GitHub Action实际成功、SHA256一致为入库标准；工作流未成功前不得将状态写为已采集。
- 其他城市地图、住房、学校医疗等资源尚需按具体许可与范围分批导入。

## 不变约束
正式游戏2026-10-09冻结；前礼务村只是观察样本；玩家未创建；31名S级NPC不冒充真实居民。
