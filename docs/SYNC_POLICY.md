# 同步和冻结协议

- 默认目标：`DARGONKNIGHT/WORLDBOOK` 的 `main` 分支；GitHub提交成功后才称为“已同步”。
- 每次后续世界书新增、修订时，先更新对应版本文件，再更新主档案、版本清单和测试状态。
- 这里的“今后同步”是未来用户与 ChatGPT 对话中，在连接可用时执行提交；**不是后台自动运行、自动监听或跨会话永久连接保证**。
- 仓库公开：严禁上传真实个人敏感资料、密钥、未经核实的居民私人资料。虚构NPC统一标S，现实可核实事实标R，未知标U。
- 游戏冻结于2026-10-09，具体时刻U；玩家未创建；前礼务村为随机观察样本，绝非玩家住址。
- 正式存档和沙盒测试独立；沙盒经济、对话和行为不得写入正式历史。
- 早期没有可用原始文件的章节为人工整理版，不能声称逐字还原。 v13/v14 的原始压缩包以聊天附件形式存在；只有实际存在于仓库中的文件才算完成GitHub同步。


## GitHub-first强制顺序（2026-10-10补充）
1. 每次编辑前读取`main`当前SHA、`AGENTS.md`、主档案、人物资料、数据manifest、相关代码与测试，不凭聊天摘要覆盖仓库。
2. 将变更的输入、证据、决策依据、测试及局限追加到`docs/decisions/YYYY-MM-DD-*.md`；不得虚构或导出内部隐藏推理过程。
3. 资源来源索引 != 真正数据；实际`data/raw`须有字节与SHA256验证；无法合法再分发的数据保留缺口。
4. 提交后验证实际分支、文件和SHA。未来离线时ChatGPT不会自行提交，只在有可用连接且用户继续任务时执行。
