# 真实性宪章 · 项目最高级长期规则 / REALISM CONSTITUTION

**地位：真实性优先于玩法便利、叙事效果和开发速度；本文件优先于世界书版本、玩法、剧情、NPC引擎、用户界面和交付便利性。适用全部未来迭代。** 用户历次改进要求——人物自主、家庭婚恋/工作/法律结构、信息隔离、无回合连续时间、Windows EXE统一目录——均源于追求现实一致性，不是让游戏看上去复杂。任何功能与现实规则冲突时，**先确保真实性，再考虑趣味性、视觉表现、剧情推进、性能和开发速度**。若现实细节尚未核实，不得为了凑功能而编造、默默填入或把S级测试包装成现实事实。可明确拒绝某项动作/保留未知/推迟开发。

## 一、七道硬门槛

1. **证据和时间门槛**：R为有来源且适用日期/区域合法的现实资料；S为明确标记的虚构或实验假设；U为未知。R不可由角色独白、旧网页索引或概率结果升级；2026-10-09正式世界只能使用时间有效的证据。真实历史不会因新模型或按钮生成。
2. **物理/地理门槛**：行动占用时间、精力、位置、交通方式和资源；同一人物不能同时在两个实体地点。在途不等于在出发地/目的地，路线、位置、到达时间未知就明确U，不会中途取消后瞬间返回。
3. **时间/因果门槛**：正式世界冻结，独立S级游戏使用单调无回合时间。NPC和玩家并行按自己的可知信息决定，消息送达/阅读与合同履约、到账相互分离。没有“NPC必须等玩家”或“玩家自动跳跃整段时间”；不同事件需记录发生时间。
4. **人物/社会门槛**：角色存在工作、日常责任、已婚/恋爱/家庭及不同社会关系，不能让所有人只围绕玩家、每次都答应、自动可联系；NPC各有独立目标、日程、知情范围与拒绝权。
5. **经济/法律/权限门槛**：未知余额≠零，报价≠合同，同意≠履约，付款≠工资，讨论≠政府批准。需要账户所有权、足额、双边账目和明确授权；机构依据真实权限、适用法规与程序运行。无法核对则不执行。
6. **系统运行门槛**：不把离线规则伪称大模型，不把浏览器挂起的模拟称为24小时后台运算，不把未采集的真实数据称为已入库，不把离线HTML改名叫EXE。运行能力必须与实际代码、部署、测试匹配。
7. **独立性/保真门槛**：所有S级NPC不冒充真实居民；人物/真实社会自动运行但只有自己实际可知的事实能影响选择；正式2026-10-09世界无玩家、时间未知、历史空，沙盒不得反写正式文件。

## 二、强制工程流程（永久执行）

每次迭代前都需要：查阅本宪章与AGENTS.md、世界书主档、相关代码、原始资料/有效期、既有测试和真实GitHub最近提交；写明现实目标、目前哪里失真、R/S/U证据、为何采用本实现和未完成缺口；改行为代码，建立或增强**针对真实因果后果的回归测试**（故意覆盖不合法条件与反例），再更新世界书及编号、最新优先更新日志、版本文件、EXE和可下载产物。

**每次改进均须能回答**：新增的真实约束是什么？角色在未获许可/未知地点/已占用时会被怎样拒绝？NPC为何拥有或没有某条信息？哪项结论是S级而非R级？角色拒绝、中断、失败有何实际后果？哪个测试验证它？若尚未达成，说清楚，而不是用“更真实”代替证据。

回归测试应保留R/S/U不可混淆、未知值不自动填入、无瞬移/越权/重复支付/信息自动共享、时间单调、可恢复且不过度模拟离线历史、编译Windows EXE并执行真实二进制自检。增加 `scripts/check_realism.py` 验证本宪章、版本索引、最新日志、核心回归测试、CI检查入口和EXE目录约束持续存在；检查器只能证明**最低工程门槛**，不能替代人工证据复核或声称完整模拟现实。

## 三、当前v36优先修复

v35只有出发区/目的区并缺真实导航。原程序在行程中途打断时继续把出发区作为当前位置，这是不符合现实的。v36引入在途与中断状态、最后确认地点与当前未知位置、目的地恢复机制。未获得路由/停车/回程事实时，不允许在出发区或目的区执行本地行动，也不允许任意改变目的地制造传送。允许保留已消耗的体力和时间；已付款与没付款、假设票价与已发生实际扣费仍明确区分。完整北京路线和GPS依旧U，不冒充真实导航。

**版本边界**：世界书v36/游戏7属于新规范及独立S级分支。它不代表已经知道具体行驶地点或现实NPC的真实行程；不能修改v35及更早已经记录的试验事实。
