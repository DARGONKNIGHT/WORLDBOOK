## 导入记录格式

当未来真实导入一个来源，需要在来源目录建立独立文件记录以下字段：

```json
{
  "resource_id": "MAP-006",
  "state": "INGESTED",
  "source_url": "<原始来源URL>",
  "acquired_at": "<实际抓取时间（带时区）>",
  "effective_at": "<数据代表的时间>",
  "source_version": "<版本/发布日期>",
  "sha256": "<原始字节校验和>",
  "crs": "EPSG:4326",
  "license_review": "<实际许可条款与引用>",
  "storage_location": "<本地路径或合法托管位置>",
  "quality_checks": ["geometry validity", "time bound", "schema validation"]
}
```

原结构模板适用于未入库资料；OSM PBF和v16局部路网现已实际生成并保存在GitHub。

## 地理和路网的执行边界

- 不将地图图层直接当作车辆实时可通行路网；需要道路拓扑、方向、车种禁限、转弯和时变事件。
- 对乡村道路、村内小路、公交站名尤其要交叉检查；OSM/城市地图均可能遗漏或出现滞后。
- 使用Tianditu时检查可用图层许可与审图号；使用OSM时检查ODbL署名和衍生数据库使用规则。
- 所有实际路程以指定时间的可用线路/交通数据为准；没有则返回估计范围和不确定性，不能虚构精确路线。

## 经济系统的执行边界

- GDP、CPI、平均工资是区域指标，不是一个随机NPC的精确收入。
- 区域租房挂牌价不是成交价，更不是整个村庄平均价。
- 企业收入、利润、现金、债务和所有者权益独立记账。
- 交易发生时才结算资金；不能因为引用官方统计数据直接改变特定NPC的银行余额。
- 2026-10-09冻结世界中不得使用其后才发生的真实经济事件作初始历史。


## v16局部OSM样本真实数据接入
OSM数据源与派生路网已经在GitHub中验证；实际地点节点前礼务村(6410843713)、生成范围2.8km、1,244节点、2,018条步行有向边和1,905条机动车有向边。原始PBF的SHA及派生图SHA记录在`../data/derived/manifest.json`。**缺失**转向关系、道路障碍、动态限行、过街安全、实际公交时刻及实时拥堵，不可宣称已完成真实导航或可靠ETA。
