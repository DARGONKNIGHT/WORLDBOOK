# 地球：现实人生｜Earth Realism Worldbook

> 版本：v14.0 · 社会模拟世界书 · 资料基准：2026-10-09（游戏内时间冻结）

本仓库保存用户与 ChatGPT 逐层构建的**真实地球完全现实模拟世界书**。世界遵守真实物理、法律、经济、人口与社会约束。NPC、家庭、机构及企业依照各自信息、职责和资源自主行动，不以玩家为中心。

## 核心状态

- **世界地点**：真实地球；中国制度详细化；北京市为当前高精度城市。
- **随机基层观察样本**：北京顺义区北小营镇前礼务村，**不是玩家住所**。
- **虚构NPC**：15名核心人物＋16名扩展候选，均为 S 级模拟人物，不冒充真实居民。
- **游戏时间**：2026-10-09，具体钟点尚未设置；游戏未开始，正式历史为空。
- **玩家**：尚未创建角色，没有确立住址、收入、家庭或职业。
- **事实标签**：`R` 可核实的现实事实；`S` 虚构模拟；`U` 未核实／未知。
- **执行限制**：没有离线运行的世界服务器；仅在明确执行测试或游戏进程时结算。
