# 《地球：现实人生》v15.0：NPC自主决策与真实生活调度（实验性沙盒）

**前置资料**：GitHub `main` 现有 `AGENTS.md`、v14事件引擎、v13正式冻结JSON、31名S级NPC及现实资料清单。v15不修改v13/v14原始文件。

## 1. 版本定位

v14确保可执行事件满足时间、空间、资金、信息与权限约束；v15为它引入 **决策候选→信息与条件检查→权重比较→冲突预约→v14执行→历史审计** 的独立层。自发行为限定为**已有目标、已知条件与事先定义的候选行为集**中的选择，不虚称具备自由意志、完整人格或自动生成所有日常行为的能力。

## 2. 决策条件

输入为人物的S级实验档案、时区明确的时刻、必要的事件日志及真实已知信息。候选项分为已经明确承诺的任务与可以不做的选项。采用可解释的序数评分 `5*necessity+4*urgency+2*preference-effort`，各要素0—5。数字是沙盒选择器的测试权重，**不是实测人类心理特征**；承诺事项在同等前提满足时先于可选行动处理。

候选事项必须满足：
- 只执行支持的 `activity` 或 `message_send`；购买、付款、雇佣、审批、法律事实和重大关系变化需另行得到实际流程批准。询价不等于合同，预算检查不等于支付。
- 人物和岗位能力可知，且拥有实际信息来源；消息仅到达收件者时才进入其知识。
- 工作日程、库存和个人财务如为未知，**不能默认开放、缺货或零元**。日期本身不会自动使所有教师在调休日上班。
- 正式存在的时间预约与现场位置必须满足；不得重复占用人物时段，也不得瞬移。
- 不重要任务可以不做，不为所有31名人物强行生成行动。

## 3. 家庭协商、商业经营与劳动安排

- 刘桂芳经营状态中的假设库存低位只能触发检查与询价，不进行自动下单。
- 李文浩的**假设**排班消息只有送达赵倩后才可能让她回复，日程冲突时可以拒绝。
- 马志强接到询价后可以选择是否报价，报价不是维修完成。
- 吴晓宁模拟教学准备仅由明确假设的个人工作日历支持，不能据此推定其真实学校或某天授课安排。
- 候选人物身份不够完整时宁可返回未建模，也不填入假造的工资、地址和婚姻变动。

## 4. 审计与保存

`planner_v15.py` 为每一个候选写入 `decision_id`、评分、提出时刻、结果与拒绝原因，已通过条件的事项才进入v14事件队列。v14已执行事件由独立哈希链历史日志记录；未执行的决策记录绝不冒充现实已发生事件。

`scenario_v15.py` 使用2026-10-09 09:00（北京时间）独立的沙盒锚点、显式编造的经营资料和地点。**正式游戏仍只有日期2026-10-09、具体钟点未知，玩家未创建，正式历史为空。** 引擎不能离线持续运行。

## 5. v15当前局限

仍无真实公交/驾车路线的分钟级耗时、交通拥堵、北京个体消费价格、全部NPC个人财务与合同、实际学校排班、真实企业系统、心理行为模型或法条自动推导。v15只验证几个可核查机制，并不宣称模拟过31人的完整日常。
